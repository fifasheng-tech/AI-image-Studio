Getting Started

Image Studio 如何工作

Image Studio 是一个本地图片生成工作台。你可以用聊天模式快速生成，也可以进入 Agent 画布，把文本、参考图、参数、生成节点和结果节点编排成一条可复用的创作链路。

它不会替你自动重试消耗费用。生成失败时会把上游错误、请求 ID 和本地日志反馈出来，方便你判断是服务商、参数、尺寸还是参考图导致的问题。

核心思路

  1. 输入你的想法。 在聊天框或 Agent 画布描述画面，也可以上传参考图。
  2. 选择正确参数。 服务商、模型、尺寸、数量和超时都会被提交给本地生成接口。
  3. 得到可继续编辑的结果。 结果图会保存到下载目录，并能作为参考图重新送回模型做二次编辑。

开始第一个项目

如果你只是想快速出图，留在聊天模式即可。输入描述、选择模板或上传参考图，然后点击发送。生成完成后图片会显示在对话流里，并保存到项目输出目录。

输出目录默认是：~/Downloads/Image Studio。项目页会从这里读取最近生成和编辑工程。

Agent 画布

画布默认是空的。你可以在右侧 Agent 输入想法，点击拆成节点；也可以从左侧把文本节点、参考图节点、参数节点、生成节点拖进画布，再通过端口连接。

文本节点

承载普通描述、局部要求或最终 prompt。

参数节点

集中管理服务商、模型、尺寸、数量和超时。

生成节点

汇总上游节点，点击后调用生成接口。

结果节点

展示输出图片，也能转为参考图继续编辑。

添加参考图

参考图可以从聊天模式上传、从画布顶部导入本地文件或文件夹，也可以从项目页导入历史生成图。参考图进入生成链路后，会自动切换为编辑/图生图模式。

选择服务商和参数

服务商设置保留内置服务商和自定义服务商。尺寸建议按最终用途选择，例如横版海报选择 16:9，竖版封面选择 9:16。自定义尺寸仍然保留。

模板和 Prompt 优化

模板适合固定业务场景，Prompt 优化适合把草稿改成更完整的模型指令。画布里可以把模板节点、文本节点和 Prompt 优化节点连接到生成节点。

快捷编辑

点击结果图后会出现图片工具栏。快捷编辑、去背景、局部重绘、编辑元素、编辑文字和多角度，本质都是把当前结果图作为参考图，再提交给上游 AI 模型进行二次生成。

项目素材

项目页按最近生成、会话上传、编辑工程分类。画布顶部的导入菜单可以选择本地单一文件、本地文件夹或项目文件。

输出文件

生成和编辑结果会统一保存到下载目录下的 Image Studio 文件夹。项目页会自动读取这个目录，让你把历史素材重新导入回画布。
